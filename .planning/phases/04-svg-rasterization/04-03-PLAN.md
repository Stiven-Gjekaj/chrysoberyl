<objective>
Make the cross-OS golden-hash test on the text-bearing SVG fixture the
phase's exit gate, and settle or withdraw the claim it tests.

Purpose: success criterion 3 is a falsification test, not a formality. The
research rates cross-platform bit-identity at medium confidence and says
why: resvg's own README states it, nobody has run this project's six
runners against a glyph, and `tiny-skia` ships SIMD enabled by default.
Phase 1 already recorded run-time CPU dispatch as the exact shape of
defect this project treats as fatal, and pinned the scalar FFT planner
because of it. The same class of risk now sits in the rasterizer, and this
plan is where it stops being a claim.

Output: two lines in the digest job, a written falsification protocol
beside them, and a recorded matrix result.
</objective>

object id, read at planning time from `HEAD` at commit `199477d`. It must
not move. This plan touches a workflow file and, only in one documented
branch, the workspace dependency table. Neither is inside the engine.

## The claim this plan must not assume

A green run on this machine is not evidence for this claim. Phase 1
recorded that two builds agreeing under Rosetta on one Mac does not prove
what a second real machine proves, because Rosetta does not expose the CPU
feature surface that would make them differ. The evidence here is the six
runner labels the matrix already names, and nothing smaller.

The three outcomes are all acceptable. Two of them are findings. Only one
of them is silence, and silence is not among them.
