images and read a structural verdict, **so that** the verdict is byte-identical
on every operating system and CPU architecture.

touches a GPU is in the comparison dependency graph. The same input gives the

planted.

story about a session somebody once ran.

## What this plan settles about DET-06

DET-06 reads: the comparison path calls no platform transcendental function,
and the build disables floating point contraction on that path. 01-RESEARCH.md
splits that into two unequal halves, and this plan records both.

The contraction half needs no work. Rust does not contract an ordinary multiply
and add. The fused-or-not choice is reachable only through an unstable
nightly-only intrinsic, never through plain arithmetic in stable Rust, which is
verified against the compiler's own documentation. There is no default to switch
off. What replaces that work is an audit of two real risks: an explicit fused
multiply-add call in the comparison path, and a dependency whose own build opts
into a fused instruction set or a fast-maths flag for its own code.

The transcendental half is exactly as large as it was feared to be, and it is
already mitigated by plans 01-04 and 01-07. This plan adds the guard that keeps
it mitigated.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source tree to guard | The guard reads the repository's own source, so a comment or a string could be crafted to hide a real call or to fail a clean build. |
| shell script to working tree | A script that edits source could destroy uncommitted work. |
| dependency tree to engine | A transitive dependency could bring a GPU or format crate into the engine without a direct edit. |
