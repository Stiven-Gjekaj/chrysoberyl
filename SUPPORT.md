# Getting help

Do you need help with Chrysoberyl? Look here.

## Learn the tool

- Start with the [README](README.md): the quick start, the formats and the
  rules.
- For the rule file, read [examples/rules/example.toml](examples/rules/example.toml).
  It explains each kind of rule.
- For the design, the invariants and the open claims, read
  [docs/DESIGN.md](docs/DESIGN.md).
- Run `chrys --help` and `chrys compare --help`.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/stiven-gjekaj/chrysoberyl/issues) first.
  Maybe a person asked the same question.
- If you found a bug, open a bug report. Include the two files that you
  compared, or the smallest pair that shows the problem, and the output.
- If a pair gives a different verdict on two machines, that is the most
  important kind of bug for this project. Include both outputs of
  `chrys compare --hash-only`.
- If you want a feature, open a feature request.

Do not use the issue tracker for a security problem. See
[SECURITY.md](SECURITY.md).
